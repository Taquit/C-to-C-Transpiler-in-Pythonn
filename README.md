# C# to C++ Transpiler in Python

This project is a simple **transpiler** that converts a subset of source code written in **C#** to **C++**. It is developed entirely in Python 3 and was built for educational purposes, demonstrating how the initial phases of a single-pass compiler work.

## Architecture

The transpiler is designed modularly and is divided into three classic phases:

1. **Lexical Analysis (Lexer)**: Takes the C# source code in plain text and divides it into logically meaningful sequences called *tokens* (keywords, identifiers, operators, numbers, etc.) using regular expressions. It ignores whitespace and comments.
2. **Syntax Analysis (Parser)**: Reads the tokens generated by the Lexer and validates them against a predefined grammar using a *Recursive Descent Parser*. If the code is valid, it generates an **Abstract Syntax Tree (AST)** that hierarchically represents the program.
3. **Code Generation (Generator)**: Traverses the AST built by the Parser and, for each evaluated node, generates and concatenates its equivalent instruction in C++ syntax.

## Project Structure

```text
Transpilador_Py_v3/
│

├── data/
│   └── c#_code.txt    # Test file with C# source code
└── src/
    ├── tokens.py      # Definition of Regex patterns for tokens
    ├── lexer.py       # Lexical Analyzer implementation
    ├── ast.py         # Definition of the different AST Nodes
    ├── parse.py       # Syntax Analyzer implementation
    └── generator.py   # C++ Code Generator implementation
```

## Supported Features

Currently, the transpiler recognizes and translates the following subset of C#:

- **Variable Declaration and Assignment**: Support for standard variables like `int`, `float`, etc.
- **Standard Output**: Direct translation of the C# `Console.WriteLine(...)` call to the equivalent C++ syntax: `std::cout << ... << std::endl;`.
- **Control Structures**:
  - `if` and `else` statements.
- **Loops**:
  - `for`
  - `while`
- **Mathematical Operations**: Relational operators, compound assignments (`+=`, `-=`, `*=`, `/=`), and increment/decrement operators (`++`, `--`).

*Note:* The transpiler is programmed to temporarily consume the structural wrapper characteristic of C# (`using System;`, `namespace`, `class Program`, `static void Main`) and focus on evaluating and translating the statements that are strictly inside the `Main` function. All translated code will be wrapped in a simple `#include <iostream>` and `int main() { ... }` block for C++.

## Requirements

- **Python 3.x**

The project exclusively uses modules from the Python standard library (such as `re` for regular expressions and `pathlib` for path management), so **there is no need to install external dependencies**.

## How to Run

1. Clone or download the repository to your local machine.
2. Open your terminal and navigate to the project's root directory (`Transpilador_Py_v3`).
3. (Optional) Edit the `data/c#_code.txt` file and enter the C# code you want to translate, making sure to stick to the currently supported subset of instructions.
4. Run the main script:

```bash
python main.py
```

Upon completion, the terminal will print three sections to the console:
1. The list of read tokens.
2. The textual representation of the derived Abstract Syntax Tree (AST).
3. The final C++ source code generated by the transpiler.
